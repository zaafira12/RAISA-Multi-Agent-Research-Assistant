# 🤖 RAISA — Multi-Agent Research Assistant

RAISA (Research Assistant Intelligent Software Agent) is an AI-powered multi-agent research assistant designed to automate literature review, research paper analysis, trend detection, research gap identification, and structured report generation using Artificial Intelligence (AI) and Natural Language Processing (NLP).

---

##  Features

-  Automated Research Paper Retrieval using OpenAlex API
-  AI-Based Keyword Extraction using KeyBERT
-  Semantic Analysis using Sentence Transformers
-  AI-Generated Research Summarization
-  Research Trend Analysis Dashboard
-  Research Gap Detection
-  Structured PDF Report Generation
-  Personal Research Library System
-  Multi-Agent Research Workflow Automation
